# Board representation experiments

Compare board inputs with a fixed-depth policy before transferring a representation to adaptive backbones. Square inputs retain all 64 square states; compact-piece inputs omit empty squares while preserving occupied square identities and all supplied metadata. Both use the lossless version-2 tokenizer. Relative geometry adds a learned attention bias for signed file/rank displacements to the same absolute square embeddings; it is not a replacement of those embeddings.

## Comparable training exposure

The three configurations in `exposure/` compare absolute squares, relative squares, and absolute compact pieces with eight layers, width 512, eight attention heads and no dropout. Absolute squares and compact pieces each have 28,498,866 trainable parameters. The relative configuration uses FFN width 1535 instead of 1536, giving 28,500,978 parameters, a difference of 0.0074%.

Use a common frozen release containing 262,144 training and 8,192 validation positions annotated by Stockfish 17.1 at depth 16 with MultiPV 4, one engine thread and 64 MiB hash, resetting search state for each position. Train on the rank-one move at the completed depth. Verify source checksums, target legality and absence of overlap by the first four FEN fields. `pondera-prepare --teacher-release RELEASE --output-dir DATA` performs these checks and writes lossless token arrays, legal action indices and a provenance manifest. Positions without game history use repetition count 1; that is an explicit input limitation, not recovered history.

Each model receives 20 passes over the same training positions, effective batch 512, seed 640, and the same shuffled order and step-indexed warmup/cosine schedule: 10,240 optimizer updates and 5,242,880 presentations. Microbatch size may change with accumulation adjusted to preserve effective batch size. This comparison controls exposure and optimization schedule with nearly equal parameter counts. It reports different theoretical FLOP costs; it does not claim to match FLOPs simultaneously. Runtime and memory determine execution settings only.

The initial objective is unmasked best-move cross-entropy. The value projection preserves the policy interface but receives no value loss. Validation every 512 updates uses all 8,192 held-out positions. A fixed, evenly spaced 2,048-position training probe measures generalization gaps. Record raw and legal-normalized loss and top-1, probability mass on legal actions, illegal raw argmax rate, entropy, confidence calibration against the teacher move, and material-count slices. Raw loss decomposes exactly into legal-normalized loss plus negative log legal probability mass. Legal sets contain board moves; draw adjudication remains external. Saved per-position validation arrays support paired comparisons; first-batch move-state changes between physical layer exits provide an internal diagnostic.

Compare trajectories against updates, presentations, FLOPs and LR progress. An early compact advantage that persists only in legality probability supports a different explanation from a sustained advantage among legal moves. Rising training–validation gaps call for a data-scale check rather than further fitting of the same positions. `legal_loss = true` enables a targeted intervention supplying legality during training, but that intervention is not part of the initial three-run comparison. Attention/state-change probes are observations, not causal explanations by themselves.

Do not select a representation solely from terminal loss. One seed is exploratory, and agreement with one teacher move is not measured playing strength. Before settling the representation, test the consequential mechanism with a targeted probe and check scale dependence on common data and targets. Comparing these results directly to smaller models trained on different labels cannot isolate model scaling. Geometry and alternative lossless embeddings remain open if the evidence motivates them; no full configuration grid is prescribed.

## Earlier fixed-compute reference

The root `absolute.toml` and `relative.toml` preserve a four-layer, width-256 reference with about 4.02M parameters, one million unique training positions, 67,866 validation positions, and a budget of 5 × 10^15 theoretical training FLOPs per run. The source is `kaupane/chess-positions`, revision `9321f3749806972a29307ea37a975c6bdcca757d`, splits `stockfish_train` and `stockfish_val`. Select 1.5M evenly spaced source training rows, exclude validation position keys, deduplicate, then retain one million evenly spaced eligible rows. Sampling gives each retained example equal weight. Compact pieces can be compared by changing `model.layout` to `"pieces"`.

That protocol indexes LR by FLOPs and permits substantially different update counts across token lengths. It measures efficiency under its compute budget, but cannot by itself distinguish architectural quality from additional training exposure. It does not establish a geometry winner or justify eliminating alternatives. Preserve its source identities and checkpoints when adding new comparisons.

For both protocols, a multiply-add counts as two FLOPs. Count dense attention and linear operations using logical token lengths, excluding padding and scalar operations; training includes forward and two backward matmuls, with only the unsupervised value projection's forward cost. Report actual totals, parameter counts, unique data, presentations, updates and LR progress together.
